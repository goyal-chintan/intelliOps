### Issues

- **Bug reports**: [Open a bug report](../../issues/new?template=bug_report.yml)
- **Feature requests**: [Open a feature request](../../issues/new?template=feature_request.yml)
- **General questions**: [Open a discussion](../../discussions) (if enabled) or an issue labeled `question`

### Response Times

This is a portfolio/learning project, not a production service. Response times
vary, but we aim to triage issues within a week.
