# Decisions (ADRs)

Use these to answer “why did you do it this way?” in Staff/Senior interviews.

How to use:
- Build using `docs/roadmap.md` + `docs/learning-book.md`.
- When you need the rationale (or you’re preparing for interviews), read the relevant decision doc here.

Index:
